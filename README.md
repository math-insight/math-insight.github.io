# Koło Naukowe Matematyki Stosowanej

Nasza strona -> [mathinsight.xyz](https://mathinsight.xyz/)

## Utrzymanie strony

To repozytorium zawiera niewielką statyczną stronę internetową KNMS Insight.

- `index.html` to strona główna
- `styles.css` zawiera wspólne style
- `script.js` zawiera logikę strony głównej
- `projects.js` zawiera dane kart projektów wyświetlanych na stronie głównej
- `more-about-projects/` zawiera podstrony poszczególnych projektów
- `images/` zawiera obrazy i ikony używane w całym serwisie

Instrukcję pracy z repozytorium, krótki tutorial i listę kontrolną przed publikacją znajdziesz w pliku
[CONTRIBUTING.md](./CONTRIBUTING.md).
